# 🎙️ React Text-to-Speech & Speech-to-Text App

A modern web application built with **React** that converts text into natural-sounding speech and transforms spoken audio back into text using browser-based speech APIs.

This project demonstrates real-time voice interaction, clean UI practices, and modern React architecture.

---

## 🚀 Features

✅ Convert text to speech instantly  
✅ Real-time speech-to-text transcription  
✅ Simple and responsive UI  
✅ Adjustable voice settings (rate, pitch, voice selection*)  
✅ Works directly in the browser — no external installation required  

> *Voice options depend on the browser.

---

## 🛠️ Tech Stack

- **Frontend:** React + Vite (or Create React App)
- **Speech Engine:** Web Speech API  
  - `SpeechSynthesisUtterance` (Text-to-Speech)  
  - `SpeechRecognition` (Speech-to-Text)
